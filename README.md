# SmartServe – Service Request Management System

SmartServe is a web-based Service Request Management System developed using Python and Flask. It helps employees raise service requests and allows support teams to track and update the status of requests through a centralized dashboard.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## Features

- User login authentication
- Raise new service requests
- Service request categories
- Priority selection
- Request ID generation
- Request status tracking
- Update request status
- Search service requests
- Filter requests by status
- Input validation
- Centralized dashboard
- Responsive user interface

## Request Categories

- Hardware
- Software
- Network
- Access
- Other

## Priority Levels

- Low
- Medium
- High

## Request Status

- Pending
- In Progress
- Resolved
